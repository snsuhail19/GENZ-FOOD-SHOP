# GENZ FOOD SHOP

A simple GitHub-ready food ordering website.

## Files

- `index.html` — main food shop page
- `style.css` — website design
- `script.js` — food menu and cart logic
- `payment.html` — order summary/payment page

## Change food names and prices

Open `script.js` and edit the `foods` list.

Example:

```js
{
  id: 1,
  name: "Samosa",
  price: 20,
  description: "Crispy potato-filled Indian snack",
  image: "IMAGE_URL"
}
```

## GitHub Pages

Upload all four files to your GitHub repository.

Then go to:

Settings → Pages → Deploy from branch → select `main` → `/root` → Save.

Your website can then be opened using your GitHub Pages URL.
